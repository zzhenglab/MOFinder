# Supporting-information PDFs

The JACS file contains synthetic illustrative text; the other two files are blank
templates. Replace the blank templates with readable documents to demonstrate all
three slots. For research extraction, supply the corresponding source supporting
information.
Filenames use the DOI with `/` replaced by `_` and append `_SI`, for example
`10.1021_jacs.2c09756_SI.pdf`. Keep `../inventory.csv` consistent with the paper set.
See the [input instructions](../README.md) before running extraction.
