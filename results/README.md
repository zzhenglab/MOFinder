# Results

New abstract-screening runs write to `abstract_triage/<run_id>/`. Generated run directories are excluded from version control. Keep each run's `run_manifest.json`, `responses.jsonl`, `predictions.csv`, reference snapshot, and subsequent analysis outputs together.

Archived model predictions for the consolidated triage workflow have not yet been included. Saved notebook displays are not a complete prediction archive. The historical `data/Section S2/` files are available in the [historical repository tree](https://github.com/zzhenglab/MOFinder/tree/bb6502b669a027ad30a26668e621515756a52c5a); they belong to earlier experiments and are not substituted automatically.

Figure source tables and model-run archives will be added with their dataset, prompt, and configuration identities.
