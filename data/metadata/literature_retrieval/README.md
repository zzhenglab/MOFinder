# Literature retrieval

This study focuses on LLM-based literature triage. To examine trends, we also
roughly divide papers into four categories: Chemical synthesis, Theory & modeling,
Crystal engineering, and Functional materials. These additional labels use keyword
rules and are not generated by an LLM. The results suggest that keyword grouping
alone is insufficient to identify synthesis-relevant papers: many papers in the
Chemical synthesis group are still excluded by triage.

Classifications are included directly in the article and supporting-information tables:

| File | Contents |
| --- | --- |
| [papers.csv](papers.csv) | Article inventory with DOI, Publisher, DOI Link, and Classification |
| [supporting_information.csv](supporting_information.csv) | Supporting-information inventory with the same columns |

Each table retains 7,437 source rows, representing 7,435 distinct DOIs.
Download progress is maintained in local working copies; article and SI documents
remain local. See the [retrieval guide](../../../docs/literature_retrieval.md)
for usage and [manifest.json](manifest.json) for file provenance.
