# Literature retrieval

Article and supporting-information inventories include keyword-based classifications:
Chemical synthesis, Theory & modeling, Crystal engineering, and Functional materials.

| File | Contents |
| --- | --- |
| [papers.csv](papers.csv) | Article inventory with DOI, Publisher, DOI Link, and Classification |
| [supporting_information.csv](supporting_information.csv) | Supporting-information inventory with the same columns |

Each table retains 7,437 source rows, representing 7,435 distinct DOIs.
See the [retrieval guide](../../../docs/literature_retrieval.md)
for usage and [manifest.json](manifest.json) for file provenance.
