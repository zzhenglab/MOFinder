# Negative reconstruction reference

`ground_truth.xlsx` contains 431 scored negative conditions and 36 optional conditions
from 100 publications in one sheet. Its 482 rows also include one row for each of the
15 publications with no annotated negative evidence. Optional annotator comments do
not affect scores.

See the [evaluation guide](../../docs/negative_extraction.md#benchmark-evaluation)
for example CSVs, commands and metric definitions.
